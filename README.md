## Want to Run the Project Yourself?

You do not need to be an expert to take a look under the hood. Here is how to open the project and try it out.

**Before you start, you will need:**

- Android Studio, which is the free program used to build Android apps
- A free Firebase account, if you want the app fully connected to its online features

**Step one. Download the project.**

```
git clone https://github.com/<your-org>/FBLA-Hub.git
```

**Step two. Open it in Android Studio.**

Open the folder you just downloaded in Android Studio and give it a minute to get everything ready.

**Step three. Connect Firebase.**

Firebase is the online service that handles logins, messages, and saved data. Create a free Firebase project, add your own setup file to the `app` folder, and turn on sign in, the database, file storage, and notifications. The Planning Document explains the role each of these plays.

**Step four. Press play.**

Hit the run button in Android Studio to launch FBLA Hub on a phone or a built in preview device.

## A Note on Safety

If you plan to share this project publicly online, please read this first.

While building the app, some private keys and passwords were saved directly inside the project files. Think of these like the keys to the app's online accounts. Before posting the project anywhere public, you should:

1. Reset every key and password, since they should be treated as no longer safe.
2. Move them out of the project files and into a secure, hidden location.
3. Clear them out of the project's saved history so old copies do not leak.
4. Tell the project to ignore those files going forward so it never happens again.

Taking these steps keeps your accounts, and any member information, protected.
